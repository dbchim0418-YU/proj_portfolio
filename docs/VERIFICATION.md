# 기능 검증 기록

배포한 사이트를 직접 열거나, 같은 결과물을 로컬 서버에서 열어 확인한 기록입니다. 자세한 화면과 판단 과정은 과제 보고서에 정리했습니다.

- 대상: https://dbchim0418-yu.github.io/proj_portfolio/
- 공개 사이트 확인 환경: Microsoft Edge 156.0.4314.50 (64비트), Windows 11 25H2 (빌드 26200.9711)
- 자동 시험 환경: Hugo extended 0.167.0으로 빌드한 결과를 Chromium(Playwright)으로 열어 확인

| 번호 | 영역 | 확인한 동작 | 예상 결과 | 실제 결과 |
| --- | --- | --- | --- | --- |
| T01 | 배포 | main에 push한 뒤 Actions 실행과 공개 사이트 반영 확인 | push마다 build, deploy가 자동 실행되고 사이트에 반영 | 성공. 언어 변경 커밋(`e176b2f`) 이후 재실행 없이 자동 배포, 변경 내용이 새로고침 후 반영 |
| T02 | 경로, 자산 | 하위 경로(`/proj_portfolio/`)에서 CSS, JS, 글꼴, 아바타 주소 확인 | 모든 자산이 `/proj_portfolio/`로 시작하고 깨진 요청 없음 | 성공. 처음에는 프로필, 배경, 파비콘이 `/images/...`로 깨짐 → 상대 경로로 수정 후 정상 |
| T03 | 메뉴, 링크 | 메뉴 클릭, 뒤로 가기, 새로고침, `#skills` 주소 직접 입력 | 주소에 앵커가 남고, 섹션 제목이 고정 메뉴 바로 아래(80px)에 표시 | 성공 (1440px, 390px). 원본 테마는 주소가 바뀌지 않아 뒤로 가기 시 사이트를 벗어났음 |
| T04 | 반응형 | 1440, 1024, 768, 720, 390, 320px 폭에서 가로 넘침과 메뉴 전환 확인 | 가로 스크롤 없음, 768px 미만에서 ☰ 메뉴 | 성공. 모바일 연구 활동 카드 폭 274px → 330px로 개선 |
| T05 | 키보드 | Tab 순서, 포커스 표시, Enter 실행, 모바일 메뉴 Esc 닫기 | 모든 메뉴와 링크에 도달, 3px 포커스 테두리, Esc로 메뉴 닫힘 | 성공. 수정 전에는 남색 영역에서 포커스가 보이지 않았고 Esc가 동작하지 않았음 |
| T06 | 접근성 | 움직임 줄이기 설정, 본문 바로가기, `lang` 속성 | 애니메이션 없이 바로 표시, 첫 Tab에 본문 바로가기, `lang="ko"` | 성공 |
| T07 | 글꼴 | 공개 사이트 캡처에서 한글 제목 속 영문, 숫자 글꼴 확인 | 제목 전체가 한 글꼴로 표시 | 수정 후 성공. 처음에는 "(5G/6G)"만 세리프 글꼴로 섞여 보였음 |
